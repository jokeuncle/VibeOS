Execution Lifecycle Sequence

sequenceDiagram
  actor U as User
  participant FE as Frontend
  participant PM as pm-agent
  participant WS as workspace-svc
  participant LLM as llm-gateway
  participant AG as Domain Agent
  participant CTX as Memory+RAG+KG

  U->>FE: 自然语言输入
  FE->>PM: POST /api/nlp
  PM->>PM: 意图分类
  PM->>WS: 读取 pipeline config
  WS-->>PM: phase_order + qualityGate

  loop 每个 enabled phase
    PM->>WS: 读取 agent config
    WS-->>PM: preferredModel + status
    PM->>LLM: check_autonomy
    LLM-->>PM: autonomy_level

    alt supervised
      PM-->>FE: approval:required (WS)
      U->>FE: 审批
      FE->>PM: POST /workflow/approve
    end

    PM->>AG: dispatch(AgentTask)
    AG->>CTX: 组装上下文
    CTX-->>AG: memory + docs + patterns + extensions
    AG->>LLM: chat(model=preferred)
    LLM-->>AG: 响应
    AG->>WS: 保存 artifacts + tasks
    AG->>LLM: report_trust_outcome

    PM->>PM: quality gate check
    alt manual gate
      PM-->>FE: approval:required
      U->>FE: 通过
    end
  end

  PM-->>FE: project:complete
